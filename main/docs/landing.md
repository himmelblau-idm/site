# Himmelblau - Seamless Azure Entra ID Authentication for Linux

## Why Himmelblau?

- ✅ **Seamless Azure Entra ID authentication on Linux**
- ✅ **Intune compliance integration**
- ✅ **Supports Native Multi-Factor Authentication (MFA)**
- ✅ **Entra Id multi-user SSH support**
- ✅ **Single Sign-On (SSO) for Firefox, Chrome and Edge**
- ✅ **Office 365 Web Apps**
- ✅ **Secure & open-source**

## Getting Started

Choose [Stable Repositories](/stable-repositories/) for maintained, versioned release packages, or [Community Nightly](/downloads/?channel=nightly) for free development builds. Vendor packages are available on some distributions.

[Start installation](/downloads/) and select your package source. Stable installation uses the URL sent automatically by email after subscribing through Open Collective. Repository access does not include technical support.
