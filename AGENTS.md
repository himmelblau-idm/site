# AGENTS.md

These are the sources for the himmelblau-idm.org website.

## Modifications

Modifications to the main site need to be made in ./main/, and modifications to the documentation are made to ./mkdocs/.

## Building

Generating the website sources (which MUST be done prior to commiting the changes) is completed as follows:

If modifying the main site (via ./main/), run: `make site`.
If modifying the documentation site (via ./mkdocs), run: `make docs`.
